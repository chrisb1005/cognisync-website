# Cognisync Automation Agents

Professional automation solutions for data processing, cleaning, and API integration.

## 📦 Quick Start

### Data Cleaning Agent
```bash
python agents/data_cleaning_agent.py input.csv output_cleaned.csv
```

### API Integration Agent  
```bash
python agents/api_integration_agent.py --action connect --service slack
```

## 🚀 How to Use

1. Clone or download the automation package
2. Install requirements: `pip install pandas requests numpy`
3. Run agents with sample data or your clients' files

All solutions are designed to run locally on client infrastructure for full control and compliance.
